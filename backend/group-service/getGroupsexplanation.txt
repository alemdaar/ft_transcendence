for the main group page,
endpoint: `GET /groups`

The page has three sections, `my groups` and `discover groups` with `pending requests`, so the endpoint is split by the `scope` query parameter:
`GET /groups?scope=mine`: return the groups the user is already a member of.
`GET /groups?scope=pending`: return the groups the user has a pending request to join.
`GET /groups?scope=discover`: return all general groups and same user's campus team groups that the user has no pending request and isn't member in.

The `Discover groups` section has a filtering feature, I added the `type` query parameter:
`GET /groups?scope=discover&type=general`: return only the general groups.
`GET /groups?scope=discover&type=team`: return only the same user's campus groups.

The endpoint has also a `search` query parameter for the search bar in  `discover groups` section:
`GET /groups?scope=discover&search=text`:  keeps only groups whose name contains the text.

`type` and `search` can be combined:
`GET /groups?scope=discover&type=general&search=text`: keeps only general groups whose name contains the text.

for the pagination feature, ther is the `page` query:
`GET /groups?scope=discover&page=2`: return the 2nd batch of groups, if no page is provided the first batch always in display.
